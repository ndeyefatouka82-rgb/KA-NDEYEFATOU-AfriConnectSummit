## Description du projet

AfriConnect Summit 2026 est un site web vitrine dédié à une conférence internationale sur l'innovation et les technologies en Afrique. Il permet aux visiteurs de découvrir le programme de l'événement, les intervenants, les informations de contact et de s'inscrire à la conférence.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

## Fonctionnalités JavaScript implémentées

- Navbar dynamique au défilementgit.
- Menu burger responsive.
- Dark Mode avec sauvegarde grâce à Local Storage.
- Bouton "Retour en haut".
- Compte à rebours en temps réel jusqu'à la conférence.
- Compteurs animés au défilement.
- Animations des sections au scroll (Intersection Observer).
- Validation du formulaire de contact.
- Filtrage des intervenants par catégorie.
- Navigation par onglets du programme (Jour 1, Jour 2 et Jour 3).
